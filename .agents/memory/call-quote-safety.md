---
name: Call-to-quote safety
description: Product requirements for evidence-based quote drafts and contractor review.
---

Call-derived quotes must not invent materials or quantities from vague enquiries. Missing call evidence should produce a useful message, not a speculative estimate. Require contractor review before quotes are delivered to clients.

**Why:** The user explicitly requested these safeguards when integrating the reviewed GitHub call-to-quote improvement, while keeping the existing BuildAI/CREWON product intact.

**How to apply:** Preserve these safeguards across quote-builder changes, mobile quoting, and any future email/SMS sending flow. AI output is a draft, not permission to send a quote.
